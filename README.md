This Repository contains an AI Analysis of RFCs looking for contradictions, ambiguities and other issues.

I created this while working on other projects that required a reading of these RFCs and I realized there were a few things that contradicted each other, so I figured why not ask AI to do a full analysis.

I will update this repo as I deal with more RFCs in other work.

Note:  The original commit contains a deep read of certain RFCs and a cursory scan of others, once I have the full read of all 408 RFCs I've been working with I will commit an updated version
